# OFCM-BiMamba

Official implementation of OFCM-BiMamba for preceding-vehicle lane-change intention prediction.

## Dataset

The dataset used in this project is available via Baidu Netdisk:

- Download link:  https://pan.baidu.com/s/1LMO5-7j5fnUraKV6vOLzCw?pwd=0663
- Extraction code: 0663

The dataset contains RGB image sequences and the corresponding optical-flow data for three intention categories: left lane change, right lane change, and lane keeping.
